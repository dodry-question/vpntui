# vpntui — панель VPN для отдельных приложений

`vpntui` запускает выбранные программы в отдельной сети через Xray: весь их
TCP, UDP и DNS-трафик идёт через подписку, а остальная система работает как
обычно. Управление — терминальный интерфейс на Textual; глобальный режим
(системный прокси или TUN) вынесен отдельно.

## Что умеет

- **VPN для любого приложения.** В разделе «Приложения» (8) показываются все
  установленные `.desktop`-программы. Для каждой можно включить правило
  «всегда через VPN» и выбрать сервер: `Авто` берёт сервер, выбранный в
  разделе «Прокси». Правило переписывает `Exec=` ярлыка, при выключении
  восстанавливает исходную строку.
- **Подписка.** `vpntui sub import <url|file>` понимает `vless://`,
  `vmess://`, `trojan://`, `ss://`, `hysteria2://`, base64-список и Xray JSON.
  При повторном импорте выбранный сервер сохраняется, если он ещё есть.
- **Серверы и правила.** Поиск, TCP-пинг, выбор текущего сервера; правила
  `DOMAIN`, `DOMAIN-SUFFIX`, `DOMAIN-KEYWORD` с целями `proxy`, `direct`,
  `srv:N`.
- **Глобальный режим.** Системный SOCKS/HTTP (10808/10809) или TUN, как
  systemd user-сервис `vpntui-xray.service`.
- **Ядро Xray.** Берётся из системы, а если его нет —
  `vpntui core install` скачивает официальный релиз и проверяет SHA-256.
- **Без вотчдогов.** Состояние читается по требованию; сессия умирает вместе
  с приложением.

## Установка

```bash
pipx install git+https://github.com/dodry-question/vpntui.git
vpntui core install          # если нет системного xray
vpntui sub import 'https://provider/sub/TOKEN'
vpntui setup                 # root-хелпер + sudoers + ярлык
vpntui
```

Зависимости Fedora: `iproute2 util-linux slirp4netns curl libnotify`.
`vpntui setup` один раз спросит пароль sudo и поставит
`/usr/local/lib/vpntui/run-vpn` и правило в `/etc/sudoers.d/vpntui`.
Само приложение и Xray в netns работают без root.

Для надёжного TUN лучше поставить ядро в системный каталог:

```bash
vpntui core install --system
```

Пользовательское ядро хелпер намеренно не запускает от root (иначе это была бы
эскалация привилегий); на некоторых ядрах создание TUN от пользователя не
сработает.

### NixOS

```nix
{
  inputs.vpntui.url = "github:dodry-question/vpntui";
  # ...
  programs.vpntui = {
    enable = true;
    users = [ "alice" ];
  };
}
```

Модуль ставит пакет, root-хелпер и sudo-правило. `vpntui setup` на NixOS не
нужен. Подготовка заявки в nixpkgs — в [NIXPKGS.md](NIXPKGS.md).

## Совместимость со старой установкой

Первый запуск читает старое расположение (`~/.config/xray`, `~/.config/vpn`,
`~/scripts/vpn`) и копирует конфиги в XDG-каталоги, ничего не изменяя в
исходных файлах. Ярлык Qoder остаётся ровно таким, какой был: если в нём уже
стоит `qoder-vpn`, правило просто помечается включённым; если стоит обычный
запуск — остаётся обычный. Новый способ управления ярлыком включается только
после ручного переключения тумблера в разделе «Приложения».

Рабочая папка `~/scripts/vpn` при этом не трогается — новый код живёт
отдельно в `~/scripts/vpntui`.

## Клавиши

`1`–`8` — разделы, `↑`/`↓` — фокус, `Enter` — действие, `p` — пинг,
`/` — поиск, `k` — завершить сессию, `l` — запустить приложение,
`s` — сервер приложения, `d` — убрать правило, `q` — выход.

## Проверка

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
.venv/bin/pytest -q
```

Тесты поднимают TUI в headless-режиме, проверяют импорт подписок всех
форматов, генерацию конфигов и переключение ярлыков; сеть и root не
используются.
